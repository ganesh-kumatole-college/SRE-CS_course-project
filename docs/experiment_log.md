# Experiment Log

Record experiment ID, date, input snapshot, configuration, command, output path,
and noteworthy observations. Do not hand-enter reported metrics here.

## Feature 5 protocol setup

The detector/evaluation layer uses the configured 90/10 normal-only split,
train-only scaling and validation-fold threshold calibration. It writes one
new run directory with resolved configuration, metrics, locked-test
predictions, environment, and Git revision metadata. Numeric experiment
results will be generated by evaluation runs in later work.

## Feature 7 experiment orchestration setup

The Phase 9 configuration and dispatcher are implemented on
`feature/run-the-reproduction-and-robustness-experiments`. The six selected
experiment configs resolve to seeds `0..29` and use the repository's concrete
organization IDs `alpha`, `beta`, and `gamma`. The dry-run command
`make PYTHON=.venv/bin/python run-exp EXP=exp07` validates configuration and
dispatch metadata. No benchmark metrics are recorded here because the local
`data/benchmark/` directory currently contains only its placeholder file.
